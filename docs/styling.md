# Styling

## Stack

- Tailwind CSS v4 via the `@tailwindcss/vite` plugin (no `tailwind.config.*`; theme lives in CSS).
- shadcn/ui with the `base-nova` style (Base UI primitives). Config is in `components.json`.
- Icons: `lucide-react`. Font: Geist Variable (`@fontsource-variable/geist`).

## Where things live

- `src/index.css` — Tailwind entry, shadcn theme tokens (`:root` and `.dark`), `@theme inline` mapping
  tokens to Tailwind utilities (`bg-background`, `text-muted-foreground`, `border-border`, ...).
- `src/components/ui/` — generated by `npx shadcn@latest add <name>`. Treat as vendored: prefer
  composing over editing; if you must edit, keep the change minimal so re-adding stays easy.
  This folder is exempt from `react-refresh/only-export-components`.
- `src/components/` (outside `ui/`) — app components.
- `src/lib/utils.ts` — re-exports `cn` (class merging) from the `cn` package.

## Theme

The app is dark-only for now: `index.html` sets `class="dark"` on `<html>`, which activates the `.dark`
token block. Use semantic tokens (`bg-card`, `text-muted-foreground`, `text-destructive`) instead of raw
palette colors so a light theme can be added later by toggling the class.

## `@/` import alias

`@/*` maps to `src/*`. It is declared in three places that must stay in sync:

1. `tsconfig.json` — `compilerOptions.paths` (read by the shadcn CLI and editors).
2. `tsconfig.app.json` — `compilerOptions.paths` (used by `tsc -b` for `src/`).
3. `vite.config.ts` — `resolve.alias` (used by Vite and Vitest at runtime).

No `baseUrl`: it is deprecated in TypeScript 6, and `paths` resolve relative to the tsconfig file.
